# Upload the complete current website

1. Extract the ZIP using Extract All.
2. Open your GitHub repository: https://github.com/jamescatral-spec/bites-care
3. Choose Add file → Upload files.
4. Drag index.html, styles.css, app.js, and the entire assets folder into the upload area. Keep the assets/pets subfolder intact.
5. Keep the repository's current config.js if you have already added your Apps Script /exec URL there. The supplied config.js is a blank configuration template; upload it only if you have not configured one yet.
6. Click Commit changes. After the Pages deployment succeeds, refresh https://jamescatral-spec.github.io/bites-care/.

Do not upload the ZIP itself or an enclosing folder. index.html belongs at the repository root. Keep Code.gs in Google Apps Script.

Included design: warm cream background, Playfair Display headings, Source Sans Pro body, 25 original Ampon Alaga profile cards, automatic crossfades, pause/play and previous/next, full-profile viewing, and cream blending for the cards. The Instagram iframe, Shop T-shirts menu link, and extra footer collection link are removed. The main Explore the T-shirts button remains.

Payments are not connected. The form handoff uses the public Apps Script URL in config.js. This package is prepared for upload and has not been committed to the repository automatically.
