# Reference cream background

The light cream sampled from the upper-left background of the supplied Native Bites reference is #FEFAF3 (RGB 254, 250, 243). The source has slight variation, so this uses a representative flat color.

Upload styles.css to the existing GitHub repository and commit. Existing navy/blue colors, fonts, shirts, and pet cards are unchanged. Config.js and Code.gs do not need changes.

If the inline form is already connected, replace Inquiry.html in Apps Script with the matching updated file and deploy a new version to match its background too.
