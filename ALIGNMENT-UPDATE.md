# Opening-section alignment

Replace styles.css in your GitHub repository, then commit. No HTML, JavaScript, config.js, or Code.gs change is required if you already use the 25-pet gallery version.

The opening text and gallery share a top edge, with consistent spacing and responsive gutters. Previous cards disappear immediately before the next card fades in, preventing overlapping profile text. Fonts, cream background, original cards, and gallery controls are preserved.
